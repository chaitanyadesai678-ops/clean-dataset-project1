
# Collect a Dataset

## Project Overview
Collect a Dataset is a simple Data Analytics web application
developed using Python, Pandas, and Streamlit.

It allows users to upload CSV datasets, view data in a table,
check dataset information, and download the processed dataset.

## Features
- Upload CSV files
- Preview dataset records
- Display total rows and columns
- Count missing values
- View statistical summaries
- Download the dataset as a CSV file

## Technologies Used
- Python
- Pandas
- Streamlit
- CSV

## How to Run
1. Install Python.
2. Install the required libraries:
   pip install pandas streamlit
3. Run the application:
   streamlit run app.py

## Dataset
A sample student dataset containing student IDs, names,
departments, marks, and attendance.
